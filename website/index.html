Design anything.
Right on your desktop.

Dupo is a Canva-style studio for documents, presentations, and videos — with a built-in MCP server so your AI agents can do the design work for you.

Get started View on GitHub 
curl -fsSL https://getdupo.vercel.app/install.sh | sh
irm https://getdupo.vercel.app/install.ps1 | iex

Everything you'd expect, natively

🎨

Canva-style editor

Drag, resize, and rotate text, shapes, and images. Layers, undo/redo, zoom, and page backgrounds.

📄

Page presets

LinkedIn posts and carousels, Instagram, X, YouTube thumbnails, A4, US Letter, or custom dimensions.

🖼️

Presentations

Slide-based projects with a present mode. Export to PDF, PowerPoint, or PNG images.

🎬

Video editor

Timeline-based editing for 1080p and vertical video projects.

⚡

Native & light

Built with Tauri 2. Small binary, fast startup, works offline. Your files never leave your machine.

📁

Plain files

Projects are open .dupo JSON files in your Documents folder. No lock-in, easy backups.

Your AI agent is the designer

Dupo ships with a Model Context Protocol server. Connect Claude, Codex, OpenCode, or any MCP client and let it list, read, edit, create, and export your projects.

claude mcp add --transport http dupo http://127.0.0.1:47330/mcp

list_projects

See every document, presentation, and video project with dimensions and paths.

read / update_project

Agents read page JSON and write back text, shapes, and images programmatically.

export_project

Render any project to PDF, PPTX, or PNG — straight from the agent.

Install

Use the install commands at the top of this page — curl for macOS and Linux, PowerShell for Windows. Or build from source with git clone https://github.com/zetahiveco/dupo and npm run tauri build.
